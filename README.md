# Work Command Center · respaldo

`wcc.html` es la página completa en UN solo archivo: diseño + datos + lógica.
Funciona aunque el servidor de Elowen esté caído: los datos del día están incrustados.

## Cómo usar
1. Descarga `wcc.html` y ábrelo con doble clic (Chrome o Safari). Todo funciona igual: pestañas, casillas, notas, calendario (con datos del día del backup).
2. Para versión online con GitHub Pages: sube este archivo a un repo como `wcc.html` + `index.html`, activa Pages, y tienes URL fija.

## Cómo se actualiza
Elowen regenera el archivo con los datos frescos del Doc y te lo entrega. Última foto incrustada: ver cabecera.
